# Learn Python 🐍 — Zach's Track

A hands-on Python course built around **your** two goals:

1. **Game dev** — Python's syntax is nearly identical to **GDScript** (Godot's main language). Learn Python, and you've basically learned GDScript too.
2. **AI** — Python is *the* language of AI/ML. Everything from ChatGPT to image generators is built with it.

## How this works

- Each lesson lives in `lessons/` as a numbered folder.
- Every lesson has a `lesson.md` (read this) and runnable `.py` files (run these).
- Exercises have `TODO` comments for you to fill in. Try them, then ask me to check your work.

## How to run any lesson file

From the `learn-python/` folder:

```bash
python3 lessons/01-hello/hello.py
```

(`python3` on Mac/Linux; on Windows it's usually just `python`.)

## The roadmap

| # | Lesson | What you'll learn | Game / AI tie-in |
|---|--------|-------------------|------------------|
| 01 | Hello & Variables | Printing, storing data | Same as GDScript `print()` & `var` |
| 02 | Numbers & Math | Calculations, types | Player health, scores, AI math |
| 03 | Strings & Input | Text, talking to the user | Dialogue, prompts |
| 04 | If / Else | Making decisions | Game logic, AI rules |
| 05 | Loops | Repeating actions | Game loops, processing data |
| 06 | Lists | Collections of things | Inventories, datasets |
| 07 | Functions | Reusable blocks | GDScript `func`, AI building blocks |
| 08 | Dictionaries | Key→value data | Game state, AI features |
| 09+ | Mini-projects | Put it together | A tiny game + a tiny AI demo |

We'll go one lesson at a time. Don't rush — typing the examples yourself and breaking them is how it sticks.
